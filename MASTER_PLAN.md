

We are currently in Stage 1 of the following sequence:

1. **Stage 1 — Python foundation:** language, compiler, serial reference
   runtime, validation, tests, reproducibility, and contracts for future
   stages. Stage 1 may design and test GUI/GPU-facing interfaces, but does not
   implement the GUI or GPU backend.
2. **Stage 2 — GUI:** authoring, run management, visualization, and inspection
   on top of the stable Python foundation.
3. **Stage 3 — GPU:** accelerated execution for selected workloads, validated
   against the Python reference runtime.

The stage-specific suggestions and preparation work are indexed in
[`docs/05-concept-improvements.md`](./docs/05-concept-improvements.md).
